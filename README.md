# US Premarket Daily Reports / 美股盘前日报

Private archive of daily US pre-market trading reports (QQQ/SPY confluence levels, scenarios, catalysts).

## Layout
```
reports/
  YYYY-MM-DD/
    YYYY-MM-DD_report.pdf   # full PDF (charts embedded)
    YYYY-MM-DD.md           # source markdown
    YYYY-MM-DD_chat.md      # 3–6 line chat summary
    YYYY-MM-DD_digest.md    # dimension digest (from 2026-10-28)
```

## Notes
- Generated by the 交易报告资料bot daily pipeline.
- Not investment advice.
- Prefer keeping this repository **private** (contains trading levels and bias).
